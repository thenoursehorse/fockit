# operator-algebra

## What is operator-algebra?

Performs operator algebra on fermions, bosons, Pauli operators, and more.

See [uv](https://docs.astral.sh/uv) for install instructions on `uv`.

## Install
```bash
uv sync
```

## Symbolic
```bash
uv sync --group sympy
```

## Tests
```bash
uv sync --group test
uv run pytest
```

## Development
```bash
uv sync --group dev
```
